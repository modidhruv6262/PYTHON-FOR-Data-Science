This repository contains an assignment exploring the role of Python in the Data Science ecosystem and the fundamental principles of Object-Oriented Programming (OOP). It includes a professional presentation and a collection of practical Python programs.

## 📂 Repository Contents

* **Python’s role in Data Science.pptx**: A 7-slide presentation covering Python's dominance in the industry and the "Four Pillars" of OOP.
* **python-for-data-science.ipynb**: A Jupyter Notebook containing 20 Python programs ranging from basic logic to advanced concepts like recursion and class-based projects.

---

## 📊 Presentation Highlights

The presentation bridges the gap between Python's versatility and its structural integrity.

### 1. Python in Data Science
* **The Core Stack**: Overview of NumPy for numerical arrays, Pandas for data frames, and Matplotlib/Seaborn for visualization.
* **The "Glue" Language**: Python excels at connecting disparate data sources, APIs, and C++ libraries into one seamless script.
* **Efficiency**: Rapid prototyping and an extensive "batteries included" standard library.

### 2. Object-Oriented Programming (OOP)
* **Fundamentals**: Definitions of Classes as blueprints vs. Objects as instances, and the use of the `__init__` method and `self` keyword.
* **The Four Pillars**:
    * **Encapsulation**: Bundling data and methods for security.
    * **Inheritance**: Deriving child classes from parents for code reusability.
    * **Polymorphism**: Allowing different classes to share the same interface.
    * **Abstraction**: Hiding complex internal details to simplify use.
* **Advantages**: Focuses on modular development, easier debugging, maintainability, and security.

## 💻 Technical Assignments (Jupyter Notebook)

The `python-for-data-science.ipynb` file includes solutions to 20 different programming challenges:

### Basic Logic & String Manipulation
* Sum of the first *n* positive integers.
* Substring counting and word frequency analysis.
* String transformations including swapping characters and conditional suffix addition ('ing' or 'ly').
* Complex string replacement logic for 'not' and 'poor' patterns.

### Data Structures (Lists, Tuples, & Dictionaries)
* Finding GCD, Fibonacci series, and the second smallest number in a list.
* Unzipping lists of tuples and converting them into dictionaries.
* Sorting dictionaries by value and identifying the highest 3 values.
* Counting element frequencies using dictionaries.

### Algorithms & Mathematical Functions
* Summation of complex odd and even mathematical series.
* Implementation of Factorial calculation using **Recursion**.
* Unique element extraction from lists using both standard logic and functions.

### Mini Project: Password Generator
A class-based implementation of a strong password generator.
* **Features**: Includes exception handling, random seed generation based on user input, and specific criteria for length and character types.
* **OOP Implementation**: Uses a `User` class to store credentials as a tuple containing user ID, name, and password.
